保留 #11 图层基线和 #13 逐组原子替换。#12 的60个候选命令与图稿不变。

本次移除 Function.toString() 生成浏览器代码的路径，直接从独立 runtime.js 读取源文本，避免 Vite 配置打包器转换函数后把服务器辅助标识带进 iframe。实际用户堆栈未取得，因此不宣称这一风险就是唯一根因。

六组使用独立 /dense 排序及常显数设置，恢复默认只清理对应设计组，不清图层设置。桌面宽度 >=1200 CSS px 展开模式优先呈现完整候选，空间不足横向滚动；更窄保持主按钮及一列小按钮。顶部状态显示实际增强组数、候选按钮数、纯图标数及回退，悬停显示可取得的错误。非默认页标为非默认页。
