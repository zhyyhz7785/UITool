# HY Ribbon 六组密度设计

仅 UITool 的 Ribbon 设计模式（原“图层设计”）。图层组原方案保留。六组配置和候选 SVG 集中在 scripts/hy3d-ribbon-design.json，共60条现有注册命令；只显示当前镜像中 status=done 的命令，缺失命令不造假。主按钮32px，48px宽；文字/纯图标小按钮20px图标、26px高，纯图标26px宽，列距2px、行距1px。高频保留文字，低频省略文字但保留完整提示和可访问名称。优先完整图层组，其他组按宽度逐步增显；拖动排序及组全部工具仍用原生机制。新版原生 split 按钮保留命令族及宏；旧 A5 仍用原有按钮和组菜单，不新增产品依赖。六组使用独立排序键，图层已有设置不变。候选图标在工具图标面板也可筛选预览。原始/A5 对照不改。完整构建和实机未运行。
