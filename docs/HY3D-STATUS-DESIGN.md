# HY3D 底栏紧凑设计（UITool 候选）

用户参考 AutoCAD 状态栏截图：布局只保留一个按钮、常用绘图辅助紧凑排列、最右端提供自定义显示菜单。仅在 UITool → HY3D → Ribbon 设计启用，A5 与原始界面不变；沿用 #23/#24 两侧面板和命令行布局。

## 空间导航

- 保留独立「模型」按钮，纸空间仅常显「布局」按钮（显示当前布局名在提示中，左键进入当前/最近布局）；右键或键盘 Shift+F10 / 上方向键打开原生布局选择器。
- 菜单保留新建布局、现有布局切换、当前布局设置（页面设置/页面设置管理器/视口设置按原生能力）、布局工作台、纸面浏览、管理布局。右键具体布局项仍走原生设置入口。
- 复用原生 `paintPaperTabs`、`openLayoutPicker`、`selectDrawingLayout` 与已有按钮动作，保留文档级状态。原生低频按钮节点仅隐藏，不删除其处理器。原生页面更新重新生成唯一布局按钮。

## 状态栏

- 26px 高、22px 按钮、16px 图标、1px 按钮间隙、HY 现有灰阶/强调色；状态提示、命令关键字、字体与保护告警保留。坐标、绘图辅助、常用工具、注释比例和通知靠右紧凑排列。
- 现有绘图辅助：对象捕捉、栅格、栅格捕捉、正交、极轴、对象追踪、动态输入、线宽，沿用原生 Registry 绑定及右键设置，不模拟开关状态。
- 常用工具增加选择循环、快速选择、全屏；单位、隔离/结束隔离、重生成可由用户勾选常显。只提供原生已注册且 status=done 的功能；AutoCAD 截图中的其他项目不虚构实现。
- 右端三横线展开「自定义状态栏」向上弹出，勾选仅决定是否常显（非 CAD 状态开关），保存于独立预览 localStorage；皮肤入口默认收纳，可恢复默认显示。窄窗口图标条支持横向滚动，菜单保持独立。
- 预览适配源以 HY3D `98a6cb88` 的 app.js 验证精确锚点；镜像接口不匹配时报告错误，不静默显示旧设计。未修改 HY3D 产品源码，不自动写回。
- 静态源代码及锚点核对完成；编译、Windows 实机、功能及不同窗口宽度验收 NOT RUN。
