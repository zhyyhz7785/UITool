# HY3D 资源 / 属性面板统一设计（UITool）

仅在 UITool → HY3D → Ribbon 设计候选启用，原始界面和 HY Ribbon / A5 保持原样。基于 HY3D main `6097b20f` 的 `ui/index.html`、`cad-workspace.js/css`、`explorer.js`、`dock_workspace.js`、`cad-panels.css` 核对；预览仍加载实际产品页面，不另画仿制界面。

- 图纸标签行只显示图纸标签和新建按钮；资源、特性重复开关隐藏，保留顶层 `#hy-dock-left/right`。不删除动态按钮节点，避免原生 MutationObserver 反复补建。
- 去掉左侧独立「绘图资源」标题行；左侧常显 文件 / 工程 / 历史 / 搜索。图层、属性不再在左侧重复显示；大纲、英文、文献、Git 进入右端省略号。原生节点及程序调用仍在。
- 右侧常显 属性 / 图层 / 历史 / 图块，旧「更多」和「钉 隐 浮 关」不占主行。省略号直接提供原生钉住、自动隐藏、浮动以及选项、单位、图层管理器；关闭使用顶部已有开关。不是新建命令系统。
- 左右同高 30px 标签行、12px 字号、统一选中态、26px 省略号。沿用产品主题变量，保留内容面板和拆分条、文件树路径工具栏、图块内部页签等。
- 菜单使用原生节点 click 或已注册 Registry 命令；支持点击外部、Escape 关闭和键盘导航。窄窗口原生折叠逻辑保留；原生历史共享容器逻辑不改，不承诺双边历史同时显示。
- 预览适配失败有明确提示，不隐藏入口。仅改 UITool 预览服务，不改 HY3D 源码，不自动写回产品。
- 静态源代码核对完成；Windows 实机、构建、菜单交互和不同宽度验收 NOT RUN。

## 侧栏拉通补充

- 资源和属性面板及其分隔线贯通绘图区和命令行的高度，直到状态栏上缘；命令行只占中间绘图区宽度，状态栏仍全宽。
- 原因：产品 `#workspace` 与 `#cmdbar` 是外层网格的相邻行，仅设置侧栏 height:100% 无法跨越命令行。候选将 workspace 跨两行，使用行子网格（row subgrid）继承实际命令行高度。
- 保留原命令行 DOM 父节点、拖动高度、浮动、隐藏逻辑。以原生绘图区边界同步命令行水平位置；不另存左右栏宽度。支持原生宽度拖动与面板开闭，实际运行待验。
- 仅作用于 Ribbon 设计候选；浏览器不支持 subgrid 时保留旧布局并输出错误。Windows 实机、构建、窗口宽度切换和浮动命令行：NOT RUN。
