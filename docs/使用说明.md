# UITool 使用说明

UITool 只保留三个内置预设：HyMdTauri、HY3D、通用模板。三个预设共用同一套设计器和属性编辑。

## 新建设计

左侧「预设」里点一张卡片。点中的皮肤成为主方案，同产品的其他皮肤附在设计里，用「视图 → 界面方案」切换。

通用模板是去掉文档业务后的工作台。设计完成后用「文件 → 导出工程 zip」。解压后的工程是独立的 Tauri 2 + React + TypeScript，不依赖 UITool。

## 打开旧设计

「打开设计…」读取 `.uitool.json`。文件如果来自已经删掉的预设，只要里面带着自己的布局和命令，就按原样打开，不会换成通用模板。有未保存修改时，读取和打开都会停下。

## 路径

在「连接」里填写每个产品的主仓和开发工作树，再点「记住路径」。

- 主仓只能读。
- 开发工作树要勾选授权，并且必须是 Git 链接出来的工作树，不能就是主仓。
- 写回前先「预览写回」。文件如果在读取之后被别人改过，写入会停下。
- 写入先写临时文件再替换，失败时留下原来的文件。

## 开发窗口

把仓库里的 `adapters/uitool-live.js` 加到本机 HY3D 或 HyMdTauri 的开发页。脚本只在 localhost 上注册。

UITool 列出实例后点「允许」。然后可以读取点中的元素、把变量应用到窗口、恢复连接前的界面。日常改界面不编译 Rust，也不重载图纸。文档正文不在可改范围内。

收下来的参数先留在设计草稿里。确认无误后，再用「确认写回」写进开发工作树。

## 变量

右侧属性的「变量」改的是产品里已经有的 CSS 变量，例如工具栏高度、图标大小、字号和间距。留空表示继续用产品自己的值。HY Ribbon 的显示方式记在 `hy3d.ui.hyRibbon`，命令仍是同一份登记。
