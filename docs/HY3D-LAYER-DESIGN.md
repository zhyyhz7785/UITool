# HY Ribbon 图层设计候选（UITool）

基于已经合入 HY3D 的 #2206 原生 Ribbon，参考用户提供的 AutoCAD / OCS 截图。只在 UITool 的“图层设计”预览模式加载候选，原 HY Ribbon / A5 和原始界面保持可对比。源文件镜像只读，未修改 HY3D 仓库。

- 左侧图层特性：32px 大图标，48px 按钮宽；右上当前图层选择框最小宽220px、高26px。
- 右下两排：关闭/打开、隔离/取消隔离、冻结/解冻、锁定/解锁，上下配对；最后置为当前/匹配图层。小图标20px，按钮26px，列距2px，行距1px。图稿为原创叠层几何及蓝/黄状态标记。
- 保留原生按钮的命令 ID、执行路径和全部工具弹层；图层设计的排序偏好使用独立 localStorage key。
- 选择框使用内存模拟图层（含开/关、冻/解冻、锁/解锁及 ACI 颜色），可选择不同状态。冻结图层在设计预览允许选中，方便观察，不表示实际 CAD 允许将其设为当前。真实 CAD 命令仍依赖产品宿主，本模式不执行文件或图纸修改。
- 候选以精确上下文补丁适配真实前端，不从未合并的 #2210 动态下载代码。旧镜像需先同步已合入的 #2206，源布局不匹配时明确报错，不静默显示旧布局。已包含该候选的产品镜像单独处理。
- #2210 是先前误放在产品侧的候选参考，不是本 PR 的合入依赖；先在 UITool 审定，后续才提交正式产品修改。
- 本次不自动写回产品，不合入 main；Windows 实机、构建未运行。尺寸是 CSS 逻辑像素设计值，非实测 AutoCAD 像素。
