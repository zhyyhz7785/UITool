# HY3D 图纸字体管理 V2 · UITool 设计候选

## 入口

在 UITool「预设 → 弹窗设计 → HY3D」选择「字体替换 / V2 设计候选」。点击「返回产品」回到现有预览。原型无需启动产品服务；独立页面 `public/hy3d-font-manager/index.html`，sandbox 隔离脚本，不接入 CAD 内核、文件写入或本机字体扫描。另有「字体替换 / 原生字体报告」，使用产品原生 `font_report.js` 和独立内存示例数据，便于与 V2 候选对照。

## 风格

以用户提供的 HY3D_Font_Manager_V2.html 为基础，保留其数据、授权和操作逻辑。使用 `template/src/theme/themes/hy-dark.json`、`hy-light.json`、`template/src/theme/hy-tokens.json` 的当前快照（主线 c31ce6ed），统一灰阶、强调色、边框、控件高度 24/28px、标题 34px、行高 40px、12px UI 文字和 4/6px 圆角。主题可在原型内切换；警告/成功色仅用于语义提示。原型使用示例 CAD 背景，不冒充实时产品。后续主题变更须同步本候选快照。

## 功能保持

第一层保留待处理筛选、搜索、列表、多选、推荐、原字体查找、替代候选、前后示意、覆盖率、字宽风险、定位、撤销、授权范围和应用。第二层保留字体详情、指定文件/目录、重新检测、映射管理、字体路径、提示策略、原字体恢复、轮廓显示、FONTALT。仅授权显示替代，不改原图；示例预览不能证明真实字宽或工程符号编码正确。文件选择与扫描、定位及设置是原型演示，不实现真实功能。

## 交付边界

不改 HY3D 产品源码、Ribbon 布局、产品同步或导出链路。不新增依赖。不合入 main。静态检查只核对原型内容和入口补丁；Windows 实机、构建和真实字体引擎验证 NOT RUN，待 hy 界面审定。
