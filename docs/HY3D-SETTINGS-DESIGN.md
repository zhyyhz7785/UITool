# HY3D 设置窗口统一设计（UITool 候选）

入口：UITool → HY3D → Ribbon 设计 → 设置。仅预览适配，不修改 HY3D 主仓或其他候选。基于 HY3D main 98a6cb88 的 settings-shell.js、settings.js、styles.css 和各 settings/sec-*.js 源码。

- 普通设置统一为「名称（左对齐） | 控件（统一起点） | 详细说明（信息图标）」，最小行高36px、控件26px、12px文字。说明默认隐藏，按需展开在该设置项下方，不挤乱同组标签。
- 使用实色主题背景、统一分组标题、细分隔线、紧凑导航；不再透出绘图网格。修改标记、选择态和现有主题继续保留。
- 通用 rowEl 覆盖全部分类，不按单个截图硬编码。界面尺寸组默认折叠；搜索继续匹配完整原说明，自动展开命中分组，不覆盖日常折叠偏好。
- 逐项核查自定义编辑器：文字样式、字体管理、附加角、对象捕捉、栅格间距、标注、单位、快捷键、命令别名。标注/单位两段已确认的静态说明并入详情；其余实时提示、校验、无图纸/空状态、冲突及自定义控件保留。复杂编辑器跨全宽，普通项控件对齐，窄面板改为两行；表格或复杂编辑器可局部滚动，主设置列表不横向滚动。
- 现有控件、即时生效、滚轮/中键、重置、导入导出、撤销、设置保存及原生搜索逻辑不重写。
- 源码锚点不兼容时显示错误，不静默回退。原生独立 options_window.html 没有作为本次 UITool 浏览器候选入口，不修改它。
- 静态源代码和适配锚点已核对；构建、Windows 真窗、各分类操作及窄窗实测 NOT RUN。
