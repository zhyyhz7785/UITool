# HY Ribbon 全页签设计（UITool 候选）

绘制页已经由 hy 审定。本次只推广其设计标准到插入、注释、视图、管理、输出、HY结构、HY沉降七页。原六组配置、60张图稿、简称映射和图层双排保持独立不变；不写回 HY3D。

## 设计规则

- 复用已审定的32/20px图标、固定双字简称、白色菜单角标、左右键执行和命令族固定/复位机制；高频带文字，低频纯图标。
- 每页明确功能组和命令优先级，原命令全部保留在原组工具菜单。只提升实际注册且 status=done 的命令；若无可用候选保留原组。
- 旧镜像原分组及新版 native CAD profile 分组均有明确候选，按实际存在的组适配，不制造虚假功能。
- 44项页签/组名配置（含旧/新版别名），273个配置槽位（含别名及重复跨页快捷入口）。新增177个页签专用 SVG 绑定，其中复用现有 CAD 包图稿并统一蓝色，关键 CAD 与结构工程命令另绘语义图标。图稿和简称独立于已审定页。
- 完整生效的页签共享左紧排、尾部留白、104px三行高度和15px组标题。窄窗可滚动，局部失败保留基线与原高度。顶部实际生效计数按当前页签计算，不再固定以六组为分母。
- 文字编辑器是独立的上下文界面，原 app_ribbon.js 已将该页从普通 Ribbon 移除，不属于本次常规页签设计。
