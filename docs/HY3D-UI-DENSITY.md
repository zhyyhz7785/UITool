# HY3D 全局界面密度与视觉统一（UITool Ribbon 设计候选）

## 范围和原则
图1属性面板为基准，图2图块工作台（创建、插入、编辑、属性、管理）统一所有 bw-* 公共控件。仅改样式与共享尺寸，不改已有功能、布局结构、命令绑定、CAD 绘图内容、各面板位置或尺寸拖动。复用现有设置 → 界面 → 界面密度：紧凑（compact）/ 舒适（comfortable）。不增加皮肤、不创建第二份 UI、不新增设置状态。

## 共用令牌（CSS Custom Properties）
| 指标 | 紧凑 | 舒适 |
|---|---:|---:|
| 普通字体 | 12 px | 13 px |
| 辅助字体 | 11 px | 12 px |
| 面板行高 | 24 px | 30 px |
| 控件高度 | 24 px | 28 px |
| 页签高度 | 28 px | 32 px |
| 常规图标 | 16 px | 18 px |
| 控件间距 | 4 px | 6 px |
| 面板内距 | 6 px | 8 px |
| 设置行高 | 32 px | 38 px |
| 状态栏 | 26 px | 30 px |
用户手动设置字号的原生 --interface-font 仍优先。大 Ribbon 命令图标与功能区已批准的行数及整体高度不做重新布局，保留其视觉层级；绘图、文字内容、图块预览几何等不受普通图标尺寸规则影响。

## 覆盖
- 主窗口标题栏、功能区、文件页签、命令栏、底部状态栏、左右面板顶部页签和菜单。
- 资源树、搜索、历史、图层、属性表、图块工作台；图块五页共用行距、边框、控件、选中态，预览框只调可见高度。
- 设置页（含 #27 按需详情），图层管理器、字体报告外壳及界面设置辅助表单。
- 同一预览页面所有原生 select/option/optgroup：显式同步深/浅 color-scheme 及前景背景，修复之前截图的深色下拉白底浅字。Windows 原生弹出层最终渲染待实机核查。保留禁用状态与现有色块、数据内容。
- 独立原生子窗口、第三方 SDK 编辑器内部、UITool 自身外壳和其他皮肤不在本次预览适配范围；移植产品时按同一套令牌继续核对。没有把所有图标/画布 SVG 强制缩放。
- 不引入依赖。基于 HY3D 98a6cb88 的 tokens.css、styles.css、cad-panels.css、block-workbench.css、history_panel.css、layer_demo.css、interface-settings.css、hy-ribbon/ribbon.css 及实际控件结构静态核对。仅 Ribbon 设计候选加载样式。构建、Windows 真窗、深浅主题下拉、两种密度切换和各功能页实机：NOT RUN。
