# 统一打印工作台 / UITool 设计候选

基线：UITool main `93ef958de12af2ad6a268bae84f02ed5139d1465`。依据：用户上传的 2026-11-13 V1 交互 HTML；HyMdTauri2 #166 的统一打印工作台实施计划，以及 HY3D #2059 / #2068 的已合入内核分工。本轮只施工 UITool 的 PT01–PT03，不把原型当成产品打印实现。

## 使用

预设 → 新建设计下方的弹窗设计 → HY3D 或 HyMdTauri → 统一打印工作台 / 设计候选。同一个 `public/unified-print-workbench/index.html`，HY3D 默认 CAD 专业示例，HyMdTauri 默认 PDF 一般示例。原生打印、页面设置和字体等入口照旧。目录不可用时备用目录仍显示两个候选。独立沙箱 iframe 不启动产品预览服务；返回按钮仅向父窗口发退出消息，父窗口校验发送窗口、候选 ID、模式与沙箱来源。

## 设计

- 右侧独立滚动设置区，中央黑色底/白色纸面，页缩略图收在下部并可折叠；真实宽高比例的纸张外框、整页/宽度及独立缩放；极窄窗口改为上下布局，不隐藏设置。
- 蓝/黑/白沿用当前 HY3D 主题候选中的颜色常量（快照，不与产品运行时主题联动）；紧凑 24px / 宽松 30px 控件、统一文字与边界。原型中额外的演示说明收进状态栏或任务查看。
- 一般/专业仅切换控件可见性，不改有效 CAD 比例、边距、纸张、窗口等。各示例来源独立保留草稿，快速打印恢复默认必须由用户明确触发。
- PDF、图片、Word/MD、PPT、CAD 五种示例。纸型/自定义毫米尺寸、方向、范围、份数、颜色、居中；专业 CAD 显示模型/布局、范围、样式表、比例、线宽、偏移、示例窗口；高级展开显示边距、顺序及可印区。
- 页码去重和越界校验、份数、纸张、边距、比例、偏移、窗口完整性校验；无效任务禁止模拟提交。系统打印、双面、DPI、拼版、透明效果及 STB 未验证，不开放有效选择。
- 任务检查弹窗展示契约草稿及模拟准备版本：有效参数变化重建模拟描述符，模式/主题/预览缩放不参加有效任务摘要。导出 PDF / 打印 / 批量发布仅显示演示任务，不调用浏览器打印、不生成或写入真实 PDF、不提交系统队列。

## 产品接入边界

原型数据不是正式 PrintJob schema，也不是固定 PDF 成果；CAD 几何、窗口范围、CTB、偏移、精确比例、图签及批量发布都是 UI 示例或参数演示，不代表已通过内核验收；页面导航中的模型/布局名称是示例，不绑定真实文档。缩略图为示意。正式版按 #166 定稿契约并复用 HyMdTauri 的 printRegistry / printService、各文档导出适配器，及 HY3D 的 kernel/plot、io/pdf、plot_cmds、workbench_plot。实际设备能力必须由宿主返回，预览、导出和系统打印必须消费同一次准备的固定 PDF 页面。图框自动识别、真实多布局队列、物理打印、产品移植均待后续，不添加第二套出图内核。
