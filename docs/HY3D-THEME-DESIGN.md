# HY3D 三主题候选配色

- 黑色（`blender-dark/dark`）：中性石墨灰；蓝色（`acad-b/dark`）：AutoCAD 2026 截图取色的蓝灰色；浅色（`acad-b/light`）：白底、灰蓝图标主体。
- 主题只依赖原生 Skin 的配色和明暗属性，不依赖密度或布局；A5（包括新版原生布局）与完整设计预览共用一个 CSS。旧 A5 不再把所有深色档覆盖成同一套色。
- 浅色图层叠片、块属性、剪贴板及其它 Ribbon 命令的 currentColor 统一为 #586879；保留显式蓝黄语义色、下拉角标、文字及图层颜色色块。保留原生命令、图标形状与布局。
- 只修改 UITool 1450 候选预览，不写 HY3D 主仓、不改变原始参照或 CAD 图元/视口 token。实际产品移植需在候选视觉确认后执行。
- Windows 真窗、前端构建、实际视觉验收：NOT RUN。

## 蓝色主题（AutoCAD 2026 参考）

依据用户提供的 AutoCAD 2026 截图（2026-11-26）按区域取主要像素色：标题/菜单/文件标签 #222933；Ribbon/属性面板/状态栏 #3b4453；属性分组 #2e3440；输入框 #4e5a6e；正文 #d9d9d9；状态栏激活色 #608fbf。悬停、选中、焦点色按 UITool 可读性设计派生，并非所有颜色均为截图原值。

仅改蓝色档及其顶部/底部背景映射；黑色、浅色及其图标规则逐字保留。不改 CAD 图元、视口 token、布局、密度和命令。未运行构建或 Windows 实机验收。
