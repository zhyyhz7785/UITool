# HY3D 三主题候选配色与命令栏行档

- 黑色（`blender-dark/dark`）：中性石墨灰；蓝色（`acad-b/dark`）：恢复 #32（85b2fb9f）的低饱和蓝灰，撤销 #33 的 AutoCAD 截图取色覆盖；浅色（`acad-b/light`）：白底、灰蓝图标主体。
- 原有黑色和浅色调色板、浅色命令图标语义色、图层颜色及原生命令均保留。
- Ribbon 设计和 HY Ribbon / A5 候选共用，原始界面不注入。所有候选绘图区黑底 #000000，网格图案保留；纸空间白纸图元、打印设置不改变。
- 图示两条顶部横带（标题/页签与文件页签）缩高：紧凑 28/24px，舒适 30/26px；不删除命令或修改 Ribbon 功能区组。
- 命令栏总行数 1–6（包含底部输入行）；保留原生默认 4 行、双击复位、箭头/PageUp/PageDown/Home/End，拖动按整行吸附。独立 localStorage 记录整数行数，不覆盖原始界面的像素偏好。窗口过小时只压显示行数，扩窗恢复；历史输出继续可滚动。
- 右端上箭头展开常用设置：1–6 行、F2 历史、英文提示、记忆淡提示（仅存在原生接口时）、停靠/浮动、更多设置；沿用原生功能，不新增命令。
- 对照 HyMdTauri2 `src/styles/shell/08-sash.css` 使用 col-resize / row-resize 和细线延时悬停、即时拖动反馈；浮动窗口标题使用 grab/grabbing。CAD 十字光标、点选框等原生 Windows 视口图形不在本候选 CSS 修改范围内。
- 适配源按原生 cmdbar_resize.js 的唯一锚点校验，镜像不兼容时显示错误，不静默改回像素拖动。
- 静态源锚点核对；前端编译、Windows 真窗及 hy 手动验收 NOT RUN。仅修改 UITool 候选预览，不直接写 HY3D 主仓。
