# HY3D 插入表格设计候选

入口：预设 → 弹窗设计 → HY3D → 插入表格；Ribbon 表格命令同用此候选。Ribbon 设计与 HY Ribbon/A5 注入，原始界面不变。

- 左侧样式、行列、尺寸分组，标签与输入框对齐；右侧结构实时预览与尺寸汇总，底部恢复默认、取消、确定。窄窗口自动改为上下排布，复用主题和密度令牌。
- 仅提交原生 TABLE 已有字段：style、cols、rows、col_width、row_height；默认值沿用原 mapper，行高随样式时不传 row_height。真实宿主使用 App.query('tablestyles') 获取样式及标题/表头信息，失败可输入已有样式名称；浏览器预览使用明确标注的示例样式，确认仅记录参数，不插入真实图纸。
- 列数与数据行数校验正整数，尺寸正有限值，预览最多 12 列 × 7 数据行，不随超大输入分配大量 DOM。标题与表头取样式，实际文字颜色、边框线宽和行高由内核决定；示意非精确 CAD 渲染。总行数只在样式已知时计算，总宽为列数乘列宽。
- 候选保持原生 argsFromForm 映射；产品移植时需要确认内核限制及原生视口键盘/浮层交互。没有实现 Excel/CSV 导入、表格样式编辑或单元格编辑，这些不属于本次 TABLE 插入参数优化。

静态核对源码接口和入口。构建、Windows 实机和交互验收 NOT RUN；仅 UITool 分支，不自动合入 main。
