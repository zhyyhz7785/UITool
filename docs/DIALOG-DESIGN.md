# 弹窗设计目录

入口：预设 → 新建设计下方 → 弹窗设计。两产品可交叉选择，不切换或修改当前设计配置；支持筛选、检索、刷新目录、复制源码位置、重开及返回产品。

- HY3D：13 个配置的原生入口（字体报告、设置、文字/标注/表格/多线样式、插入表格、图案填充、图块、图层、关于、打印、页面设置），另保留 V2 字体设计候选。原生字体报告用独立内存模拟缺字、候选及授权；文件/目录选择不访问磁盘。其他原生命令可能需要真实文档、选中对象或内核，未检测到窗口会提示，不冒充成功。
- HyMdTauri：关于、未保存文档确认、注册/授权、右键菜单及子菜单，使用 1460 工作树 Vite 的真实 React 组件，1461 loopback 独立预览页面，仅浏览器模式。若端口冲突或模块入口变动，显示错误。无真实文档、授权、磁盘写入；原生注册行为由浏览器平台限制。
- 动态扫描产品镜像（HY3D ui，HyMd src/packages，镜像缺失时原工作树）中的弹窗/模态/浮层/设置候选文件。扫描属于启发式源码发现，不是完整运行时弹窗清单：排除测试、生成目录、符号链接和超大文件；尚未适配的文件只展示源码路径，不伪造可交互窗口。新增组件需配置实际入口和安全示例数据。
- 仅 UITool 开发预览；不修改产品源，不新增依赖或验收门禁。此目录提供独立调试入口，暂未提供针对所有原生弹窗的可视化属性写回编辑器。

静态核对入口与源码接口；编译、Windows 实机和功能验收 NOT RUN。

## HY3D 高级文字编辑器（MTEXT / HyMdTauri 原生）

入口仍在弹窗设计 → HY3D → 高级文字编辑器 / HyMdTauri 原生。替换 #44 的固定 HY3D 界面快照：直接通过 HyMdTauri 的 1460 Vite 工作树及隔离的 1461 实验页加载原生组件，不复制、不重写编辑器、鼠标菜单或排版算法。源码核对基准 HyMdTauri2 main 77bc7301ae2c865567fdf4581504190a7ba03b10；实际运行使用本机已同步工作树。

- `HymdEditor.tsx`：原生正文；左键拖选触发 `MarkdownSelectionBar`，右键调用 `openEditorCommandSurface`，原生插入和块级分栏/比例拖动保留。
- `LayoutPreviewPane.tsx`：原生页面设置、纸型/横纵、四边边距及联动、栏数/栏距、标尺、真实分页、缩放和页码。纸张设置通过原生视图胶片状态保存到内存，不用 CSS 多栏模拟。
- `AppRuntimeProvider` 与 `openMarkdownDraft`：提供内存文档、原生命令运行时。两模式使用同一个文档，切换前 flush，IME 输入中不切换。仅适配入口和最少的正文/排版切换条；不改变产品代码、存盘协议或授权。
- 1461 浏览器隔离环境，没有真实图纸、原生 Tauri IPC；untitled 文档与视图胶片不落盘。产品依赖由原有预览工作树提供，若缺少服务/组件则明确报告。删除旧快照及专用 1450 路由。仅 UITool 审定，未同步 HY3D。

Windows 实机、构建、功能验收 NOT RUN。

### 高级文字：原生主题及 Excel 式表格

- 右侧直接挂载 HyMdTauri `AuxiliaryBar`（内含原生 `ThemeGalleryPane`），默认打开主题；原生 `Sash`/`useShellSashes` 支持调整宽度，顶部主题按钮开关，不另做样式画廊。正文与纸面共用主题状态。
- 示例普通 GFM 表格通过原生右键命令 `upgrade-to-sheet` / `upgradeGfmTableToSheet` 升级为 Univer 工作簿；随后用 HyMdTauri 原生 sheet overlay 编辑、保存快照、再降级为普通表。原生升级需要写外置 snapshot，故仅在独立 1461 实验页通过 `setPlatformForTest` 注入内存文件系统；命令与编辑器宿主桥解析同一 untitled 路径。不会写真实磁盘或接入 CAD；重开页面丢弃示例和快照。切到纸面前要求先关闭原生表格编辑面板。未接入本机 XLSX 导入/导出；并非实际 Microsoft Excel 应用。未更改产品授权。
- 代码与接口静态核对；构建和实际主题/升级/工作簿交互 NOT RUN。
