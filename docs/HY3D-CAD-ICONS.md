# HY3D CAD 命令图标候选包

- 权威清单：HY3D 2fb353c2e0c0945cf402d8d9980dca324eafb733 的 ui/commands.json 及 17 个 include。
- 457 个命令逐一映射。239 条采用重绘图稿，218 条沿用 HY3D 现有几何图稿并统一外层描边。统计的是命令映射数，不是独立图形数；同义命令允许共享几何。
- OCS 参考：OpenCADStudio 的 assets/icons/line.svg、trim.svg、offset.svg、fillet.svg 与 src/ui/icons/grid.rs，借鉴主对象/操作色/辅助线、夹点及像素网格思路；本包不引入 OCS 或 AutoCAD 原图路径。
- 新图稿使用 24×24 viewBox、1.5 单位描边、统一圆端/圆角；currentColor 为主体，蓝色 #4d95e8 表示操作、夹点或结果，虚线表示辅助或原位置。保留已有图稿的显式填充和细节属性；未做逐图光学校准或 OCS 的物理像素网格重写。
- 左侧工具图标面板在 CAD 预设显示全部命令，按类别、搜索、重绘/沿用过滤，16/20/24/32px 深浅对照。真实产品预览 1450 在读取命令注册 JSON 和 icons.svg 时加载同一包；原有布局、逻辑及非命令图标不变。
- 较新或较旧 HY3D 镜像中的已知命令会映射，未知命令保留本机原图；不可宣称覆盖未来版本。预览不写产品源码。
- 显式写回脚本：node scripts/gen-hy3d-icons.mjs 仅预检，追加 --apply 才会写入已授权 HY3D 工作树。源命令集合不一致则拒绝；只写 icon 字段及 sprite，保留其余数据。使用现有授权检查和逐文件原子替换；跨文件不是事务，建议在干净独立分支执行并审查 diff。
- 本次未执行 Windows 真窗、完整前端构建及逐图视觉验收。先由 hy 审查候选包，不直接改产品主线。
