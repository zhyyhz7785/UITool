# Ribbon 命令族（UITool 候选）

仅 Ribbon 设计模式。保留六组已有常显槽位、排列、图层组、原始/A5 对照。命令族配置来自原生 ribbon.json 的 face/menu 和已登记的同类命令；只显示运行时 status=done 的成员。共16个候选入口，若镜像只实现一个命令则不显示三角。新版 native slots 中的其它画法与宏继续可用；旧版补充原生测量宏。没有新建 CAD 命令。

- 左键主体执行当前显示命令；点击小三角或右键主体打开同一个菜单。
- 菜单左侧点击立即执行一次，不改变常显图标；右侧“固定”只切换该槽位显示及以后左键命令，不立即执行。✓表示当前常显。恢复默认仅清除该槽位固定选择。
- 初始常显命令、命令顺序和图层设计保持原样。可选命令即使已是另外一个常显按钮，也不会挪走原位置。
- 独立 localStorage key uitool.ribbon.family.faces.v1，槽位 ID 与被固定的命令 ID/宏分离；命令不可用时回退默认，不写产品设置和源码。
- 大按钮三角在下方、小按钮三角在右边，占12px；沿用20/32px图标、26px行高。使用原生 makeCmdButton 执行命令，当前候选图稿优先，其余采用实际注册图标，不再制作虚假命令。
- Esc、外部点击关闭，Shift+F10 / Alt+Down 可打开菜单；实际 CAD 执行仍取决于原有预览宿主能力。Windows 真窗尚未执行。

## 角标与双字标签（后续设计）

取消单独占宽的三角箭头条；每个可用命令族使用主按钮的独立同级菜单按钮，绝对定位到 20/32px 方形图标的右下角，默认深色主题暖黄色、浅色主题蓝色，悬停青色。角标为 9/11px，内部下三角，保持独立点击、右键和键盘交互。主按钮高度与菜单无关，宽度分配不再加 12px。

常显短标签通过 shortLabels 人工映射，文字固定 24px（12px 字号），文字小按钮固定 54px，纯图标 26px，大按钮 48px。菜单、提示、可访问名称仍使用原完整名称。固定新命令时只改变图标、简称与执行对象，不改变槽位宽度；未知的长名称暂用图标与完整提示，不强行截断。已认可图层组仅统一右侧“当前/匹配”文字宽度，保留图层选择框、图稿、双排间距。仅 UITool Ribbon 设计模式，不修改产品源码。
